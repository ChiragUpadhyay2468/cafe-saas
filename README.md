# Cafe SaaS Website

A modern cafe website built with React, TypeScript, and Vite.

## Features

- Responsive navigation bar
- Hero section with cafe image
- Featured food menu
- Food cards with pricing
- Cafe-themed styling
- Reserve Table and Explore Menu buttons

## Technologies Used

- React
- TypeScript
- Vite
- CSS
